GitHub

One control plane for your NetBox fleet

Manage shared NetBox configuration with Git-backed review.

NetBox Manager helps teams create, review, publish, search, migrate, and export data across multiple NetBox instances—without giving up GitHub as the source of truth.

Read the user guideView on GitHub

Capabilities

From reviewed configuration to daily operations

Use one interface to coordinate consistent changes and operational work across your NetBox environments.

Configuration as code

Manage device types, custom fields, reference data, and tenant permissions as reviewable YAML in GitHub.

Safe fleet publishing

Preview differences, open pull requests, enforce approval gates, publish to selected NetBox instances, and detect drift.

Search and fleet insight

Search infrastructure across instances and inspect health, versions, plugins, response times, and device-type coverage.

Migration and export

Plan tenant-scoped migrations with mapping review and export inventory to CSV or Excel using standard and custom fields.

Access automation

Apply Git-backed tenant permission templates while scoping user roles to the instances and repositories they need.

Auditability

Keep an audit trail, attribute pull requests to their requesters, and optionally forward audit events to syslog.
